# Contributing to Wildfire-The-Architecture-of-Surrender

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Wildfire-The-Architecture-of-Surrender.git`
3. Create a feature branch: `git checkout -b feature/your-feature`

## Making Changes

1. Make your changes
2. Test if applicable
3. Commit with clear messages
4. Push and open a PR

## Workflow Guidelines

- Use kebab-case for workflow filenames (no spaces)
- Place all workflows in `.github/workflows/`
- Include `name:` at the top of each workflow
- Use `permissions:` block for security

## Code Style

- YAML: 2-space indentation
- Include descriptive comments
- Use meaningful names for jobs and steps

## Questions?

Open a Discussion for questions about contributing.
